# Drafting a reply email

A reply email is a draft for the reviewer. It is not sent automatically.

Start with "Dear colleague,". Quote the request reference, such as REQ-001. State the category, the priority and the response target: 1 working day for High, 3 working days for Medium, 5 working days for Low. Say what the team will do next, using only the facts in the request and the guidance notes. Sign off as the Digital Services Team.

If information is missing, say which fields are missing and that work cannot start until they are provided. If the request needs a person, say that it has been queued for review rather than promising that the work is done.

End the draft with a line that tells the reviewer to check it before sending.
