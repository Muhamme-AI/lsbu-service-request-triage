# Reporting and system integration

Reporting requests need the data sources, the measures, and how often the dashboard or report should refresh. Do not promise a figure that is not in the request.

Integration requests connect two systems, for example a form and a finance workflow, or a tracker and Teams. Assess data ownership, security and who will support the connection before design work starts. If the opening of the request is "connect" or "synchronise" but the submitted type says something else, flag the mismatch and ask the requester to confirm the type.

Archive steps are part of the integration only when the request says records should be stored after approval.
